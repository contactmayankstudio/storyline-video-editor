# Integration Plan: Pro Features Merge

## 1. Overview
This document outlines the strategy for safely merging the three "Pro" features generated by the Graphics VFX, Animation, and Typography agents into the main `storyline` codebase without conflicts.

## 2. Feature Areas and Affected Files

### A. Color Grading & Blending Modes (Graphics VFX Agent)
- **Target Files**: `engine/core/clip.h`, `engine/commands/command_manager.cpp`, `engine/backend/gpu/*` (shaders).
- **Changes**: Adds `BlendMode` and `LUT` type enumerations to the Clip structures. Adds parsing logic in `command_manager.cpp` to deserialize blend/LUT configurations.

### B. Keyframe Easing (Animation Agent)
- **Target Files**: `engine/core/text_overlay.h`, `engine/commands/command_manager.cpp`, `engine/core/easing_logic.cpp` (new).
- **Changes**: Adds `EasingType` and `EasingCurve` to `text_overlay.h` inside `TextKeyframe`. Adds Bezier curve logic via a new `easing_logic.cpp`. Updates `command_manager.cpp` to parse easing JSON.

### C. Advanced Typography (Typography Agent)
- **Target Files**: `engine/core/text_overlay.h`, `engine/backend/gpu/text_renderer.h` & `.cpp`.
- **Changes**: Adds new styling fields (Stroke, Drop Shadow, Background Box) to `TextOverlay` in `text_overlay.h`. Updates `text_renderer` to utilize these styles.

## 3. Merge Strategy (Conflict Resolution)

### 3.1. `text_overlay.h` Merge
Both Animation and Typography agents modify `text_overlay.h`. Since they modify distinct subsets of the data structure, they can be combined sequentially:
1. Apply Typography agent's styling fields directly to the `TextOverlay` struct.
2. Append the Animation agent's `EasingType`, `EasingCurve`, and `TextKeyframe` enhancements to the same file.

### 3.2. `command_manager.cpp` Merge
All three features require new parsing logic in `command_manager.cpp`.
1. Append `ParseColorGrading` and `ParseBlendMode` logic for clips.
2. Enhance `ParseTextOverlay` to include parsing for Stroke, Shadows, and Background Boxes.
3. Enhance `ParseTextKeyframes` to parse `easing` (type, cp1x, cp1y, cp2x, cp2y).

### 3.3. Build System (`CMakeLists.txt` / Gradle)
Ensure that any new files introduced (e.g., `easing_logic.cpp`) are registered with the Android/Native build system.

## 4. Execution Steps
1. Retrieve agent artifacts from their respective `<appDataDir>/brain/<conversation-id>` directories.
2. Sequentially update `text_overlay.h` to incorporate both Easing and Typography changes.
3. Add `easing_logic.cpp` to the `engine/core/` directory and update the build script.
4. Apply shader and text rendering adjustments.
5. Integrate all JSON deserialization enhancements into `command_manager.cpp`.
6. Compile via `./gradlew :app:compileDebugKotlin` and build a test APK.
