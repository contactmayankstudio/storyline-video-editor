## **PART 4: APP ICON GUIDANCE**

### Icon Concept
**Visual Elements**:
1. **Play Triangle** (primary symbol)
   - Bold, filled triangle pointing right
   - Positioned center-left
   - Color: White or light gradient
   
2. **Edit Pen / Cutter** (secondary symbol)
   - Slim diagonal pen or cutter blade
   - Overlaid on play triangle (top-right)
   - Color: Accent teal (#00C2A8)
   
3. **Timeline Bars** (tertiary accent)
   - 2–3 thin horizontal bars at base
   - Represents layers/tracks
   - Color: Orange accent (#FF6A00)

### Color Palette

| Element | Color | Hex Code | Use |
|---------|-------|----------|-----|
| **Primary Gradient** | Purple → Orange | #6A00FF → #FF6A00 | Background |
| **Accent 1** | Teal | #00C2A8 | Edit symbol |
| **Accent 2** | Orange | #FF6A00 | Timeline bars |
| **Glyph/Symbol** | White | #FFFFFF | Play triangle, pen |
| **Dark Option** | Dark gray | #1F1F1F | Alternative background |

### Background Style
- **Shape**: Rounded square (12–16px corner radius)
- **Effect**: Smooth linear gradient (purple top-left → orange bottom-right)
- **Shadow**: Subtle inner shadow (depth, 2–3px, black @ 10% opacity)
- **Margin**: 10% padding around design (safe zone)

### Sizing & Scalability

| Size | Use | Notes |
|------|-----|-------|
| **512×512** | Upload to Play Store | Master icon |
| **192×192** | Android launcher | Typical home screen |
| **144×144** | Tablet UI | Android tablets |
| **96×96** | App drawer | Lists in Google Play |
| **72×72** | Small UI elements | Push notifications |
| **48×48** | Smallest readable | Watch/Wear OS |

**Critical**: Test that icon is recognizable at all sizes, especially 48×48

### Design Rules

✅ **DO**:
- Keep shapes simple (bold, readable)
- Ensure 2–3 color elements max
- Use flat design (no realistic shading)
- Test on dark & light backgrounds
- Avoid text/small details
- Make glyph contrast (white on gradient)

❌ **DON'T**:
- Use photorealistic images
- Add fine details (get lost at small sizes)
- Use too many colors (confusing)
- Put text on icon (unreadable)
- Copy competitor icons
- Use transparent background (Play Store needs solid)

### Icon Variations

**Light Mode Icon**:
- Gradient: Purple → Orange
- Glyph: White (#FFFFFF)
- For: Home screen (day mode)

**Dark Mode Icon**:
- Gradient: Dark blue → Dark purple
- Glyph: Light blue (#00C2A8)
- For: Dark launchers, night mode

**Feature Graphic** (1024×500):
- Left side: Large app icon
- Center: Tagline: "Fast. No Watermark. Offline."
- Right side: Sample UI screenshot or timeline mockup
- Colors: Match icon palette (gradient background)
