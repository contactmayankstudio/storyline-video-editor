DESIGN DECISIONS
================================================================================

1. THIN UI LAYER
   Why: OpenGL context is thread-local; cannot be shared between threads
   Benefit: Main thread never blocked on GL → no jank, no ANR
   Pattern: VN Editor, KineMaster, Premiere Pro

2. NATIVE GPU RENDERING
   Why: Hardware acceleration needed for 60fps real-time effects
   Benefit: Mobile phone GPU is fast (dedicated chip)
   Pattern: Verified by billions of mobile users daily

3. THROTTLED SCRUBBING
   Why: User can drag at 120fps, but FFmpeg decode is ~33ms
   Benefit: Prevents seek backlog, keeps UI responsive
   Throttle: 50ms minimum between seek calls (enough for smooth scrubbing)

4. MATERIAL DESIGN 3
   Why: Professional apps follow Material Design
   Benefit: Accessibility, modern aesthetic, user familiarity
   Colors: Dark theme (#111, #1a1a1a, #4db8ff)

5. HANDLER-BASED PLAYBACK
   Why: Non-blocking way to advance time on main thread
   Benefit: Simple state machine, easy to pause/resume
   Interval: 30fps (33ms) to match decode latency
